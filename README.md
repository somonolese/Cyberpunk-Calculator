

# Cyberpunk-Calculator (CALC)
A futuristic Cyberpunk-themed Calculator with glowing neon visuals inspired by sci-fi interfaces. Designed to combine a modern cyber aesthetic with smooth and responsive calculator functionality.


✨ Features

🔹 Neon Cyberpunk UI

🔹 Responsive design for desktop and mobile

🔹 Basic arithmetic operations (+, −, ×, ÷, %)

🔹 AC (Clear) and Backspace functions

🔹 Smooth hover and glow animations

🔹 Hidden Easter Egg (1 + =)

🔹 Lightweight and fast


🎨 DESIGN;

The interface is inspired by futuristic HUDs and cyberpunk aesthetics, featuring:

✨Electric blue neon glow

✨Dark futuristic background

✨Minimalist button layout

✨Soft lighting and animated effects
